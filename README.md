# BH Construções — Site DEMO

Website institucional de demonstração comercial para **BH — Construção Civil e Obras Públicas, Lda.** (Coimbra).

## Stack

- React + TypeScript + Vite
- Tailwind CSS v4
- Framer Motion
- React Router
- Lucide React

## Desenvolvimento

```bash
npm install
npm run dev
```

Abrir `http://localhost:5173`.

## Build

```bash
npm run build
npm run preview
```

## Notas

- Conteúdo de portfólio marcado como **demonstrativo** (BH-D0X).
- Formulários validam e simulam envio — sem backend nesta demo.
- Logo oficial e favicon gerados a partir do monograma BH.
